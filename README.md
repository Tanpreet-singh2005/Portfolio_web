# Portfolio_web

## Tanpreet Singh — Full-Stack Software Engineer Portfolio

Personal developer portfolio built with Next.js, React, Tailwind CSS, and Framer Motion.

### 🚀 Featured Live Platforms
- **[Zerodha Trading Simulator](https://zerodha-7xzj.vercel.app/)** — Real-time distributed stock trading platform with cross-domain JWT authentication and `<150ms` latency engine.
- **[TanRoam](https://tanroam.onrender.com/)** — Vacation rental and booking platform with Airbnb-inspired data architecture and +30% page load optimization.
- **[Job Portal Web Application](https://job-portal-beige-eta.vercel.app/)** — Dual-role career platform with RBAC security and 2-click application workflow.

### 🛠️ Tech Stack
- **Framework:** Next.js (App Router, Turbopack)
- **Library:** React 19
- **Styling:** Tailwind CSS & Glassmorphism design tokens
- **Animations:** Framer Motion
- **Icons:** Fluent UI & React Icons
- **Form Handling:** Formspree (`https://formspree.io/f/xyekkpve`)

### 📦 Local Development
```bash
npm install
npm run dev
```

### 🚢 Production Build
```bash
npm run build
```
